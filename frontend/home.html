Build a house, bend a beam, see why it holds

ArchiTwin is a simulator for first-year architecture students. Change the size, material and span of a small building and watch which beams sag too far.

Every number is worked out in your browser and explained in plain words, so you learn the reason as well as the answer.

Open the studio

Two-storey timber house with a gable roof. Drag to turn it.

What you can do

Change a design

Set floors, bays, spans, roof and material. The 3D model rebuilds as you move each slider.

Check every beam

Each beam passes or fails the span/250 sag limit, with a plain note on what to change.

Compare and save

Save versions, set two side by side, and see which numbers moved and why.

How it works

  1. 1

    Pick a starting design

    Choose a small house, a two-storey house, a hall or a shed.

  2. 2

    Change one thing

    Make a beam deeper, switch timber to steel, or shorten a span.

  3. 3

    Read the result

    See which beams now pass, how far they bend, and why.

Read how deflection works

What it is not

A teaching aid. It checks one thing, how far beams sag, using simplified maths and rounded material values. It is not a structural safety check, so ask an engineer about any real building. See the sources and limits.
