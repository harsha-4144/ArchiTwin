# Architectural Digital Twin cum Simulator

Run: `./run.sh` (Linux/WSL/Mac) or `run.bat` (Windows), then open http://localhost:8000.

See ADT_Plan.pdf and CLAUDE.md. Fallback demo: prototype/digital-twin-simulator.html

Tests: `python -m pytest` and `node --test frontend/tests/*.test.mjs` (the bare directory form fails on Node 22).
